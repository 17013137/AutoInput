# AutoInput

## 녹화 클립과 조합

1. **3초 후 대상 창 지정**을 누르고 녹화할 창을 선택합니다.
2. 오른쪽에서 다음 녹화 이름을 적고 대상 창으로 돌아갑니다.
3. 기본 단축키 **F7**로 녹화를 시작하고 키 입력을 한 뒤 **F9**로 종료합니다.
4. 저장된 클립을 선택하면 키 누름/떼기, 시점, 이전 이벤트와의 간격을 확인할 수 있습니다.
5. 위 녹화 목록의 클립을 아래 **타임라인**으로 드래그해서 배치합니다. 삽입선 위치에 연결되며 같은 클립을 여러 번 추가할 수 있습니다. 타임라인의 블록을 드래그하면 순서가 바뀝니다. **조합에 추가** 및 ←/→ 버튼도 사용할 수 있습니다.
6. 조합 항목을 선택하고 반복 횟수 및 매회 뒤 대기를 바꾼 다음 **적용**을 누릅니다.
7. 전체 반복 횟수를 설정합니다. 대상 창에서 **F6**으로 재생하고 **F8**로 중지합니다.

**무한 반복**을 체크하면 전체 반복 횟수 입력이 비활성화되고 조합을 계속 반복합니다.
설정한 조합 중지 키 또는 모두 중지 키, 중지 버튼, 대상 창 변경으로 종료할 수 있습니다.
해제하면 기존 전체 반복 횟수로 돌아갑니다. 무한 반복 선택은 이번 실행에서만 유지됩니다.

기본값은 로그 미리보기입니다. 실제 입력은 왼쪽 **로그만 실행**을 해제해야 합니다.

녹화/편집 결과는 실행 파일 옆 `recordings.xml`에 자동 저장되고 다음 실행 시 복원됩니다. 이전 저장본은 `.bak`에 남습니다.
여러 클립으로 구성한 한 개의 조합을 지원하며, 여러 조합 프리셋과 이벤트 직접 편집은 아직 지원하지 않습니다.

타임라인 블록 폭은 반복과 매회 뒤 대기를 포함한 재생 길이에 비례합니다. 초 단위 눈금과 1회 전체 길이를 표시합니다.
확대 값을 올리면 가로 스크롤로 짧은 클립을 자세히 볼 수 있습니다. 블록 위에 마우스를 올리면 이름과 길이가 표시됩니다.
블록을 클릭하면 반복/대기 설정이 선택되며 **적용**으로 반영합니다. 드래그 변경은 자동 저장됩니다.
타임라인 블록을 클릭하고 **Delete**를 누르면 해당 배치만 제거하고 자동 저장합니다. 녹화 원본은 유지됩니다. 타임라인에 포커스가 있을 때만 작동하며, Delete를 전역 단축키로 설정했더라도 이때는 타임라인 삭제가 우선합니다.
이번 타임라인은 클립을 순서대로 연결하는 단일 트랙입니다. 자유 위치 배치, 중첩 트랙, 클립 자르기 및 탐색기 파일 드롭은 지원하지 않습니다.

녹화는 지정 창이 활성화된 동안만 수행하며 창이 바뀌면 종료합니다. 재생과 녹화는 동시에 실행되지 않습니다.
현재 설정된 단축키 및 합성 입력은 기록하지 않습니다. 녹화 전에 다른 키를 모두 뗀 상태에서 시작하세요.
키 자동 반복 down은 하나의 누름/떼기와 유지 시간으로 기록합니다. 텍스트 편집기의 자동 글자 반복이나 IME 변환 결과를 재현하는 기능은 아닙니다.
녹화 시작부터 첫 입력까지, 마지막 입력부터 종료까지의 대기 시간도 포함합니다. 종료 시 눌린 키는 클립 끝에 해제 이벤트를 추가합니다.
클립 한 개의 한도는 10분 또는 약 20,000개 이벤트입니다. 한도에 도달하면 녹화를 종료하고 저장합니다.
설정된 키는 전역 예약 키이며 다른 앱과 충돌하면 적용 실패를 안내합니다.
녹화는 키 동작을 저장하므로 테스트 중 입력한 내용도 파일에 남을 수 있습니다.

`Recording.cs`는 녹화 데이터, 키보드 hook 및 조합 재생을, `RecordingStudio.cs`는 클립 관리와 파일 저장 UI를 담당합니다.
검증: `./test.ps1`로 순서/반복/대기 시간, 중지 및 포커스 변경 시 키 해제, XML 저장 왕복을 확인합니다.

## 빌드와 실행

Windows / .NET Framework 4.8 WinForms 기반 녹화 전용 프로그램입니다.
PowerShell에서 `./build.ps1`을 실행한 뒤 `bin/AutoInput.exe`를 엽니다.
Visual Studio에서는 `AutoInput.csproj`를 엽니다(.NET 데스크톱 개발 및 4.8 타기팅 팩 필요).

F6은 지정 창에서 조합을 즉시 재생합니다. 재생 버튼은 3초 후 활성 창에서 조합을 재생합니다.
단축키 등록에 실패하면 실행을 막습니다. 대상 창을 다시 열었다면 재지정하세요.
녹화 클립이 있어도 조합이 비어 있으면 재생하지 않고 조합 추가 안내를 표시합니다.
입력 타이밍은 실시간 보장이 아니며 게임에서 실제 동작은 검증하지 않았습니다.

## 코드 읽는 순서

- `Program.cs`: 시작점
- `MainForm.cs`: 녹화/재생 제어, 단축키, 대상 창 지정
- `RecordingStudio.cs`: 클립 목록과 조합 편집, 파일 저장
- `Recording.cs`: 키 기록과 시간 순서에 따른 조합 재생
- `KeyboardSender.cs`: Windows API 호출

## 단축키 설정

메인 화면 오른쪽 상단 **키 설정**을 누르면 별도의 설정 창이 열립니다. 바꿀 키 칸을 클릭하고 원하는 키를 직접 누른 다음 **적용**합니다. **기본값**으로 초기 설정을 불러오거나 **취소**로 변경을 버릴 수 있습니다. 현재는 수정키 조합 없이 단일 키를 지원합니다.
입력 칸에서는 Tab/Enter/Escape도 키 지정으로 처리되므로 다른 항목과 적용/취소 버튼은 마우스로 클릭하세요. 지원하지 않는 입력은 기존 값을 유지하고 안내합니다.

| 동작 | 기본값 |
|---|---|
| 녹화 시작 | F7 |
| 녹화 중지 및 클립 저장 | F9 |
| 조합 시작 | F6 |
| 조합 중지 | F8 |
| 모두 중지 / 대기 취소 | F10 |
| 현재 활성 창을 대상으로 즉시 지정 | F11 |

시작과 중지는 별도 동작입니다. 녹화 중 시작 키를 다시 눌러도 중지되지 않습니다.
시작은 지정 대상 창에서만 작동하고, 중지는 다른 창에서도 작동합니다. 대상 지정 키는 유휴 상태에서만 작동합니다.
녹화/재생/시작 대기 중에는 설정을 변경할 수 없습니다. 설정 창이 열려 있는 동안 기존 전역 단축키 등록을 해제해 해당 키를 입력할 수 있습니다. 적용하면 새 키를 등록하고, 취소하거나 창을 닫으면 기존 키를 다시 등록합니다.
설정은 실행 파일 옆 `hotkeys.xml`에 저장되며 다음 실행 때 복원됩니다. 화면 안내도 현재 설정을 표시합니다.
중복 키는 거부하며 Windows 등록 실패나 저장 실패 시 기존 설정으로 복원합니다. 복원까지 실패하면 실행을 막고 안내합니다.
일반 문자도 선택할 수 있지만 프로그램 실행 중 전역 예약되므로 F1~F11을 권장합니다. F12는 Windows 예약 키라 제외됩니다.
단축키 변경 후 기존 클립의 입력이 새 단축키와 겹치면 재생을 막고 겹치는 키를 안내합니다. 다른 단축키를 선택하면 기존 클립을 그대로 사용할 수 있습니다.
